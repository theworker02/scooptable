# scooptable

Scoop timestamps and table durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/scooptable/

## Install / run

```bash
git clone https://github.com/theworker02/scooptable.git
cd scooptable
node src/cli.js
node --test
```
